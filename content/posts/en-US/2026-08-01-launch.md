## Why we built this

Content is a static site's hardest problem, not its easiest one. We wanted the authoring experience of WordPress without a database, and without PHP running in production.

Jamground is the result: a **schema-validated** content contract, checked in CI, with an editing shell that runs entirely as _WebAssembly_ in the browser.

- No database — content is files in git
- No PHP on any server we operate
- Every entity validated against its schema before it ships

Read more about the identifier format in the [ULID specification](https://github.com/ulid/spec).
